A program that writes one haiku about debugging — three lines in the 5-7-5 syllable shape — to `entry.txt`.

```
A red breakpoint holds
the night's last log line lies still
and the fault was mine
```

## Run it

```sh
python3 main.py
```

Writes the haiku to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Deterministic, no network, no model calls.
